# 已知限制与未实现功能

v2 提供受控诊断及单独批准的 custom Shell，面向排障与部署；安装不依赖 Codex。以下内容没有被包装成“已完成生产验收”。

1. **企业真实环境未验证。** 没有企业 Web 堡垒机、实际 Web 启动器参数或目标 Linux 测试账号；没有改动这些配置。真实 SSH/堡垒机兼容性、企业审计、签名要求、20 个真实 SSH 窗口负载需现场验收。
2. **不能接管旧二进制进程。** 只有运行改造程序的窗口才有 Native Bridge。原先未改造的已打开窗口无法事后添加；需经原 Web 流程新开本次程序窗口。
3. **需要人工逐条确认。** 无 Agent 的任意终端无法可靠自动识别空闲 Shell、未提交输入、sudo 密码提示或一切交互程序。本版自动检查认证、备用屏幕、原始鼠标、粘贴和 Backend 状态，并要求用户在目标窗口明确确认空闲 POSIX Shell/空行；不符合或无法确认就拒绝。未实现全自动无人值守 Shell 判断。
4. **自定义命令也有边界。** diagnostic 仍为五模板；custom 本地单独授权后允许自定义命令、管道、重定向及多行 POSIX 脚本，每条完整脚本再批准。每次最多 2048 UTF-8 字节，转义发送行小于 4000 字节，观察最长一小时。没有任意二进制按键、自动密码输入、交互式编辑器控制、Ctrl+C 或服务器 Agent。sudo/安装/修改操作依赖已有权限或用户批准的非交互方式。每会话只有一个未解决命令，大部署需拆为可审阅步骤，不承诺任意交互式部署都能无人值守。
5. **脱敏是尽力而为。** 认证/信任提示会关闭 Bridge，疑似秘密文本行被过滤，但跨页切分、未知格式、编码、长行、任意文件内容和恶意输出无法保证识别所有秘密。开启观察即授权该窗口新输出被本机 Codex 读取并可能发往模型提供方；含秘密的会话应保持关闭。没有承诺企业 DLP/合规认证。
6. **没有完整屏幕语义。** 原字节在内存捕获，经 UTF-8 安全文本转换返回；ANSI、退格、回车、TUI 布局按可见转义展示。非 UTF-8 编码会有替换字符。没有屏幕/历史快照，没有 raw 二进制 MCP 导出。
7. **完成标记不是可信远程 Exec。** 随机 RS/US 边界适用于协作的 POSIX Shell；敌对 Shell/主机能够伪造或阻止完成。结果是终端 transcript，可能含回显和相邻输出。缺口、断线、超时和人工干预保守返回 unknown/timeout，不伪造退出码。
8. **取消不保证终止。** Native 明确确认没发送时可取消；投递与本地批准存在竞态，取消请求返回 unknown。没有默认 Ctrl+C，也不会自动重试。未知任务要由人工确认 Shell 恢复后再执行新任务。
9. **内存与历史有界且会丢失。** Broker/Adapter 重启不持久化任务或输出；新客户端不能取得旧客户端任务所有权。Native 离线期间可丢副本，输出间隙和游标明确披露。任务终态仅保留约 10 分钟。
10. **跨进程撤销存在传播延迟。** 本地关闭立即停止新采集和发送；Broker 收到断连后清理历史和权限，但无法撤回已被 Codex 读取的数据。旧在途消息/既有授权副本不能获得分布式零延迟撤销保证。
11. **安全边界为 Windows 同用户。** ACL、远程客户端拒绝、对端 PID/Token/创建时间检查已实现；不防同 SID 恶意程序、管理员、调试器或能代替用户点击的自动化软件。没有签名绑定或跨用户通信。
12. **审计为有界元数据日志。** v2 路径为 `%LOCALAPPDATA%\PuTTY-AI-v2`，与旧版分开；轮转、当前用户 ACL、无明文终端内容和自定义脚本；崩溃可能丢队列中尚未写盘的事件，不能代替堡垒机的持久审计。
13. **性能报告范围有限。** 提供 C SPSC 微基准、20 个模拟 Native 的真实 Windows Named Pipe 压力、实际 PuTTY 原版与 AI 关闭的 GUI 对比，以及 Broker 崩溃时合成 C 前端事件响应。没有声称已经测得开启 AI 的真实 SSH 端到端吞吐、网络延迟或输入响应，也没有以一次采样证明性能提升。
14. **平台限制。** 本机 Windows x64；不支持 WSL/Linux/macOS/远端 Codex 直接访问 Windows Named Pipe。没有安装服务或自动启动项，Broker 会在 Adapter 退出后继续独立空闲运行，需用户结束进程或保留供其他客户端使用。
